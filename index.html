E8 Reasoning Engine

Deterministic 64-state reasoning model over 6 binary axes (Abstraction, Scope, Method, Depth, Mode, Stance). An Observer classifies each step — no neural network, no sampling. It doesn't approximate; it inhabits.

SEAL Self-Evolution Loop

27-stage pipeline that snapshots, analyzes, self-edits, applies, rewards, and absorbs improvements. Each stage can skip, promote a new champion, or roll back. The agent gets better over time.

VSA HyperCube

4096-dimension vector-symbolic knowledge store using MAP operations (bind / bundle / permute). 16 semantic axes for compositional knowledge representation and associative recall.

GWT Attention Routing

Global Workspace Theory routing with 11 specialist modules competing via salience computation. Coalition formation and decay prevent fixation.

ConsciousnessTree

11-branch meta-cognition loop (Soil → Roots → Trunk → Branches → Fruits → Core) tracking cross-domain health, module maturity, and evolution velocity across 7 domains.

Zero Unsafe. Zero Lock-In.

0 unsafe code in core. 8,771 test functions. SQLite KB with FTS5 + BM25 + quality-ranked retrieval. Any LLM provider. CLI + Tauri desktop app.

NT-SHIELD

Security domain with sandboxing, credential vault, proxy pool, fingerprint management, and reasoning-trace protection (PII / injection / divergence scans).

Model-Agnostic Gateway

Pluggable LLM provider interface with OpenAI-compatible server mode. Drop into OpenCode, Aider, or any custom OpenAI-endpoint tool.

Persistent Knowledge Base

SQLite-backed KB with full-text search, embeddings, BM25 ranking, retraction-aware quality ranking, and untrusted-content fencing.

50+ CLI Commands

Session, file, git, KB, skill, goal, plan, review, sandbox, osint, and consciousness commands — a full developer toolkit in the terminal.

Tauri Desktop App

59 command modules with agent view, chat, command catalog, and live awareness panels. ⌘K palette across the unified bridge.

Self-Healing Loop

Daemonized background loop (60s tick) for absorption, repair, governance, and consciousness monitoring — the system watches and repairs itself.
