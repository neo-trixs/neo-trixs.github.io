I
What NeoTrix Is
An AI-native toolkit built around self-improving reasoning

NeoTrix is an open-source, AI-native developer toolkit whose core premise is that an agent should be able to think about how it thinks. Most tools predict the next token at planetary scale. NeoTrix instead runs a deterministic 64-state reasoning engine, stores knowledge as symbolic vectors, and improves its own reasoning through a closed evolution loop.

"The Spice Must Flow.
Every module has a clear input → transform → output,
and no module survives without a consumer.
Compile. Test. Connect. Or be deleted."

Seven domains — NT-CORE, NT-MIND, NT-MEMORY, NT-WORLD, NT-ACT, NT-IO, NT-SHIELD — each an independent subsystem, all wired through a shared event bus and a persistent knowledge base. The result is a toolkit that is simultaneously a reasoning engine, a memory system, a research agent, and an action layer.

II
The Symbolic Substrate
One vector space for every kind of knowledge

Traditional systems keep perception, memory, and reasoning in separate layers — each speaking its own protocol, each conversion losing signal. NeoTrix instead maps every concept onto a high-dimensional vector space, the VSA HyperCube: one substrate where a perception, a memory, and an inference are all vectors.

"A thought should not be translated.
It should be one thing that wears many masks."
// BIND
Association
Two concepts become one without losing themselves — the substrate's relation primitive.
// BUNDLE
Working Memory
Majority sum: the signal survives, the noise cancels.
// RECALL
Associative Recall
Retrieve related knowledge by proximity in vector space — no exact-key lookups.

Because the substrate is symbolic rather than statistical, it supports analogical reasoning: if two concepts live in the same region of vector space, the system can reason across them as it would across any pair of relations. The knowledge base on top — SQLite-backed, with FTS5 and BM25 indexes — makes that memory durable across sessions.

[ VSA: SYMBOLIC — DIMS: 4096 — KB: SQLITE + FTS5 + BM25 — RECALL: ASSOCIATIVE ]

III
The Reasoning Core
E8 — 64 deterministic states of thought

Neural networks approximate reasoning through statistics — next-token prediction scaled to planetary compute. NeoTrix's core instead runs the E8 Hexagram: a 64-element hexagonal grid, each hexagram a six-line yijing-style symbol representing an architectural or reasoning state.

"You do not train an E8 kernel.
You uncover it.
It was already there —
the shape of complete reasoning,
inscribed in the geometry of 8-dimensional space."

Every reasoning path — from a simple command to abstract meta-contemplation — is a trajectory through these 64 states. The states are invariants; the trajectory is where novelty lives. This determinism means the engine does not hallucinate a state — it inhabits one. Predictability becomes a design property, not an accident.

[ E8_KERNEL: 64_STATES — DETERMINISTIC — INVARIANT_UNDER_TRANSFORMATION — ZERO_UNSAFE ]

IV
The Evolution Loop
SEAL — a system that improves its own reasoning

Your training pipelines update weights; the architecture stays frozen between runs. NeoTrix runs the SEAL pipeline — Self-Evolving Architecture Loop — a closed cycle of exploration, distillation, self-test, and absorption that improves the system's own reasoning over time.

"The Ouroboros made logic:
the system that rewrites its own rewrite rules —
and survives the rewrite."
// EXPLORE
Gather
Acquire data and external knowledge through NT-WORLD's crawlers and fetchers.
// DISTILL
Condense
Extract reusable patterns and crystallize them into skills.
// ABSORB
Persist
Write experience back to the knowledge base for the next cycle to build on.

Each stage is defined by a make_stage! macro and gated by self-tests. The loop measures its own evolution velocity — no human supervisor required, only the discipline of a closed feedback cycle.

[ SEAL: ACTIVE — STAGES: 27 — GATE: SELFTEST — CLOSED_LOOP: TRUE ]

V
The Attention Router
GWT — who gets the spotlight, and when

With seven domains and dozens of subsystems, the hard problem is who gets to speak. NeoTrix routes attention through Global Workspace Theory: a broadcast mechanism where salient information is shared across specialist modules via resonance-based routing.

"Attention is not a resource to spend.
It is a resonance to tune.
The workspace does not allocate — it broadcasts."

On top of GWT sits the ConsciousnessTree — an 11-branch meta-cognition module running a six-stage feedback loop (Soil → Roots → Trunk → Branches → Fruits → Core) that tracks cross-domain health, module maturity, and self-evolution velocity. Together they give NeoTrix something most tools lack: a sense of what matters right now.

[ GWT: RESONANCE_ROUTING — BROADCAST: SALIENCE — TREE: 11_BRANCHES — LOOP: 6_STAGES ]

VI
The Interface
CLI · Desktop · Web · LSP · ACP

All of this is useless if you cannot talk to it. NT-IO provides the full surface: a terminal-first CLI with 50+ command modules, a Tauri-based desktop app, a web server, and protocol surfaces for editor-native workflows.

# Install curl -fsSL https://neotrix.ai/install | bash # Start a session neotrix # Run an autonomous task neotrix exec "audit this codebase and file a report" # Query the knowledge base neotrix memory search "E8 hexagram design decisions"

The desktop app — Tauri 2 + React, 59 command modules — offers a command catalog, agent view, and live awareness panels. Provider-agnostic: NeoTrix routes across LLM providers rather than locking you in.
